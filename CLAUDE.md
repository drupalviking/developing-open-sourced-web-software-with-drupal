# Developing Open Sourced Web Software with Drupal

An open (CC BY-SA 4.0) site-building book for people who have never seen Drupal.

- Read `README.md` (layout, commands, status) and `PROJECT-LOG.md` (decisions, open items, backlog) first.
- For any work on a chapter, use the `write-chapter` skill (`.claude/skills/write-chapter/SKILL.md`).
- Edit `manuscript/`, never `book/` (generated by `python3 tools/build.py`; commit both).
- One chapter at a time: ask the author questions about scope before drafting, and wait for their
  review before starting the next chapter.
- `archive/` is out of the book; don't build from it or edit it.
