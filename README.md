# Developing Open Sourced Web Software with Drupal

An open book about building websites with Drupal, for people who have never seen Drupal before. It
is written for the Drupal Open University Initiative, and for anyone to use, share, and improve:
university and college courses, Drupal in a Day workshops at DrupalCons and Drupal Camps, and the
curious reader on their own.

The book is about **site building**: installing Drupal, structuring content, building pages, and
running a site, all in the browser and with a few commands. It does not teach writing modules.
That is the job of the companion book, *Drupal Module Development for Drupal 11 and 12*, which
picks up where this one ends.

Throughout the book the reader builds one site: a website for a **small photography club that also
goes hiking**: *Lens & Trail*, in Edinburgh, in English and Spanish. Each chapter adds to the site from the chapter before.

## Writing

The manuscript is plain Markdown. Obsidian works well: open the repository as a vault. The
settings in `.obsidian/app.json` make Obsidian write standard Markdown links and put pasted images in
`manuscript/images/`.

- Images: `![What the image shows](images/07-manage-fields.png)`, followed by
  `*Figure 7.3: Caption*` on its own line. No Obsidian `![[wiki links]]`; the build fails on them,
  because GitHub can't show them.
- Notes to yourself or other authors: `%% like this %%`. They never reach `book/`.
- Files the reader sees (a `recipe.yml`, a piece of `composer.json`) live in `examples/` and are
  included, so the book shows the exact file that was tested:
  `<!-- include: examples/recipes/photo_club/recipe.yml -->`. See `tools/build.py` for the options.
- US spelling.

Each chapter follows the same pattern: what you'll learn, the sections with "Try it" steps on the
photo club site, a summary, **exercises**, and "Want to know more?". Where Drupal core and Drupal CMS
differ, the chapter shows both. The details are in `.claude/skills/write-chapter/SKILL.md`, which
also guides Claude when it drafts a chapter.

## Building

```bash
python3 tools/build.py           # build book/ from manuscript/, remove files with no source
python3 tools/build.py --check   # fail if book/ is out of date
```

Run the build and commit `book/` with your manuscript changes.

## Check before publication

Facts about releases and products that change quickly. Re-check each before a release.

- Drupal CMS screens (installer, site templates, dashboard) are from Drupal CMS 2.1 (2026). Retake
  the screenshots for the version the book is released with.
- Chapter 1: Drupal CMS "launched in 2025" with "an SEO toolkit, Drupal Canvas, optional AI tools" and site
  templates (new.drupal.org/drupal-cms describes Drupal CMS 2.0, 2026-11-04). The European Commission is named
  as a Drupal user.
- Chapter 1: *Default Admin* (built from Gin) is experimental in 11.4, and stable and the Standard profile's admin
  theme in 11.5 and 12 (checked in core's 11.4.x, 11.5.x and 12.0.x branches on 2026-11-04, before 12.0.0-rc1).
  Re-check on the release.
- Preface and Chapter 4: Drupal CMS has no published 3.0 or Drupal 12 date (2026-11-04: latest 2.2.8, no 3.x
  branch; plan issue drupal_cms#3501710 says Drupal CMS should support Drupal 12 the day it's released; #3591487
  switches Drupal CMS from contrib Gin to core's Default Admin). Check which version and core it's on before
  writing Chapter 4.
- Preface: "Drupal 12 was released together with Drupal 11.5, and for a site builder the two are the same" (from
  drupal.org's release schedule, 2026-11-04: both in the week of 7 December 2026; the feature claim follows core's
  release policy). Re-check after the release, and check that every contributed module the book uses has a
  Drupal 12 release.
- Chapter 1, WordPress table: checked against wordpress.org on 2026-11-04 (six predefined roles, new ones with
  `add_role()` or a plugin; custom post types with `register_post_type()`; the Query Loop block; widgets and widget
  areas). Re-check with the WordPress release current at publication.
